Dictpin은 Electron, 로컬 SenseVoice 음성 인식, 사용자가 명시적으로 정한 개인 사전 규칙, 호환 서비스의 선택적 텍스트 다듬기를 사용하는 Windows 데스크톱 음성 입력 앱의 개발 후보판입니다. 짧은 메시지, 메모, 이름, 전문 용어를 입력할 때 시작하고, 말하고, 확인한 다음 복사하면 됩니다.

> **소스 코드로 제공하는 개발 후보판입니다.** 저장소: [chenjinxian1/Dictpin](https://github.com/chenjinxian1/Dictpin). 프로젝트의 독자적인 코드와 원본 자산은 chenjinxian1 명의의 MIT 라이선스로 공개하며, 제3자 구성 요소에는 각각의 조건이 적용됩니다. 검증된 설치 프로그램이나 릴리스 다운로드는 아직 없습니다. Dictpin은 예비 이름 중복 조사를 거친 이름이며 상표 사용 가능성을 보장하지 않습니다. 패키지 식별자와 데이터 경로는 기존 이름을 유지합니다. 이 프로젝트는 Typeless와 독립적이며 공식 제휴 관계가 없습니다.

## 현재 구현된 기능

- **로컬 음성 인식:** CPU에서 실행되는 SenseVoice와 Silero 음성 활동 감지를 사용합니다. 자동으로 클라우드 음성 인식으로 전환하지 않습니다.
- **명시적인 사전 교정:** 올바른 용어와 자주 발생하는 오인식 표기를 선택적으로 등록합니다. 로컬에서 가장 긴 일치 규칙을 우선하여 한 번만 치환합니다. 동음이의어를 추측하거나 자동 학습하지 않습니다. 변경 내역을 확인하고 되돌릴 수 있습니다.
- **다듬기가 끝나기 전에도 텍스트 사용:** 곧바로 편집하거나 복사할 수 있습니다. 어느 쪽이든 진행 중인 다듬기를 종료하며, 늦게 도착한 응답이 그 버전을 덮어쓰지 못합니다. 음성 인식 원문도 따로 남습니다.
- **명시적 복구:** 완료된 텍스트는 보존하고, 제한된 미처리 PCM만 취소 후 30초 또는 인식 실패 후 최대 5분간 메모리에 유지합니다. 재시도는 명시적으로 실행하며 원격 다듬기를 사용하지 않습니다.
- **작은 작업 공간:** 결과, 사전, 설정 페이지와 떠 있는 녹음 막대로 구성됩니다. 밝은 테마와 어두운 테마, 고대비, 동작 줄이기, 키보드 포커스를 구현했습니다.
- **선택적 텍스트 다듬기:** 텍스트 Chat Completions 서비스를 사용합니다. **매끄럽게**(기본값)는 군말과 반복을 지우고, 말을 고친 경우 마지막 표현만 남기며, 말로 나열한 항목을 목록으로 정리합니다. **가볍게**는 문장 부호와 문장 구분만 추가합니다. 로컬 검사는 삭제만 허용하고 내용 추가는 허용하지 않습니다. 실패하거나 4초 동안 응답이 없거나 12초 제한에 도달해도 로컬에서 교정한 초안을 계속 사용할 수 있습니다.

실용적인 장점은 표현을 직접 통제할 수 있고, 오프라인 사전 규칙을 적용하며, 즉시 다시 녹음하지 않고도 복구할 수 있다는 점입니다. 모든 상황에 적용되는 정확도, 지연 시간, 메모리 사용량, 경쟁 제품 대비 성능은 주장하지 않습니다. 번역, 질의응답, 내용 확장, 대규모 기록 대시보드는 범위에 포함하지 않습니다.

## 사용 흐름

```text
직접 시작 → 선택한 마이크 → 로컬 음성 인식
         → 명시적인 사전 규칙 → 선택적 텍스트 다듬기
         → 확인 / 편집 → 직접 복사
```

녹음 세션과 로컬 디코더는 각각 하나만 실행합니다. 멈추면 수락한 구간을 완료한 뒤 선택적인 다듬기와 전달을 진행합니다. 다듬기 중 편집·복사는 다듬기를 종료합니다. `Ctrl+Enter`는 전체 결과를, `Ctrl+C`는 일반적인 선택 영역을 복사합니다. 복사 단축키는 기본 미설정입니다.

## 긴 받아쓰기, 이어 쓰기와 보호된 붙여넣기

이제 녹음 중부터 용량이 제한된 로컬 파이프라인으로 음성을 전달합니다. 쉬는 지점을 우선해 최대 20초씩 나누고, SenseVoice 하나가 순서대로 인식합니다. 녹음 중에도 텍스트를 미리 보고 저장할 수 있습니다. 세션의 60초 제한을 없앴습니다. 30분, 100,000자 또는 인식 대기 누적 시 보호 장치가 녹음을 멈추며, 수락한 오디오를 조용히 잘라 버리지 않습니다.

**Append more**는 수동으로 편집한 앞부분을 유지하고 다음 녹음을 이어 씁니다. 단축키 이어 쓰기도 설정할 수 있습니다. 이전 텍스트는 다시 다듬지 않으며, 자동 전달은 새 부분만 보내 중복 붙여넣기를 방지합니다. 복사는 전체 결과를 대상으로 합니다. 인식 중 미리보기는 읽기 전용이며, 다듬기 중 편집하거나 복사하면 다듬기를 종료합니다.

**보호된 자동 붙여넣기는 기본적으로 꺼져 있습니다.** 별도 Windows 도우미를 빌드하고 설정을 켜서 저장한 뒤, 지원되는 편집 가능 입력란에 포커스를 두고 단축키로 시작하세요. 명시적으로 멈춘 뒤 한 번만 붙여넣기를 시도합니다. 암호, 터미널, 관리자 권한 앱, 확인할 수 없는 컨트롤과 포커스·커서·프로세스·클립보드 변경은 전달을 막습니다. Dictpin 안에서 직접 멈춘 경우에만 원래 입력란으로 복귀를 시도하며, 무관한 앱을 강제로 활성화하지 않습니다. 앱 안에서 시작하면 수동 복사를 유지합니다.

전달 시 클립보드를 새 텍스트로 바꿉니다. 이전 내용은 읽거나 백업하지 않습니다. 키 전송은 대상이 실제로 받았다는 증명이 아닙니다. 결과가 불확실하면 원래 입력란을 확인하며 자동 재시도하지 않습니다. 전달 중에는 시작·이어 쓰기·편집을 차단합니다. 보호 정지나 복구는 자동 붙여넣기를 허용하지 않습니다.

완료된 텍스트는 저장합니다. 제한된 **미처리** PCM만 취소 후 30초, 인식 실패 후 최대 5분 동안 메모리에 보관합니다. 명시적인 재시도만 가능하며 원격 다듬기는 사용하지 않습니다. 긴 녹음 전체의 보관 기능이 아니며, 만료·삭제·종료 시 임시 오디오를 지웁니다.

끊임없는 발화의 강제 분할은 경계 단어에 영향을 줄 수 있습니다. 실제 마이크, 입력 컨트롤, 포커스, 클립보드와 비교 성능은 별도 검수가 필요합니다. Typeless보다 우수하다는 주장은 하지 않습니다. [변경 기록](../../CHANGELOG.md)을 참고하세요.

## 빠른 시작: 개발 환경 준비

**현재 대상 플랫폼은 Windows x64입니다.** Node.js **24 이상**을 설치하세요. 외부 리소스인 Electron **44.8.0** 전체 배포본, sherpa-onnx **1.13.8** 공유 런타임, SenseVoice int8 모델과 토큰, Silero VAD 모델, 별도의 Local03 네이티브 worker를 준비해야 합니다. 이 리소스들은 저장소에 포함되어 있지 않습니다. 정확한 디렉터리 구조와 공식 다운로드 출처는 [설치 안내](../INSTALL.md)를 따르세요.

리소스를 준비한 뒤 저장소 루트에서 실행합니다.

```powershell
.\native\build-local03.cmd
.\native\build-delivery.cmd
npm run doctor
npm run check
node scripts/package-inputs.cjs
npm run dev
```

루트 스크립트는 Node 내장 모듈을 사용하므로 루트에서 별도로 의존성을 설치하는 단계는 없습니다. `doctor`는 기존 디렉터리 구성을 확인하며, 새 환경 설치나 음성 인식 품질을 검증하지는 않습니다. `dev`는 녹음을 시작하지 않고 개발 프로필을 엽니다. 과거의 bootstrap 또는 resume 스크립트로 앱을 실행하지 마세요.

**API 없이 로컬로 사용하려면** **文字整理**(텍스트 다듬기)를 꺼 두세요. **设置**(설정)에서 Windows 녹음기가 실제로 사용하는 마이크를 선택하고 **保存更改**(변경 사항 저장)를 누른 뒤 직접 받아쓰기를 시작하세요. 저장하지 않은 장치 선택은 적용되지 않습니다. 녹음을 끝내고 결과를 확인한 다음 복사합니다. 단축키는 필요한 경우에만 설정하세요.

`npm run check`는 앱 구문, 로컬 의존성, 배포 대상 파일과 문서를 검사합니다. 테스트, 성능 평가, 이전 화면과 내부 공개 준비 도구는 이 저장소에서 제외합니다. [검증 및 빌드 상태](../INSTALL.md#validation-and-build-status)를 확인하세요. 검증된 설치 프로그램 빌드 명령은 없습니다.

## 선택적 API 설정

**设置 → 模型连接**(설정 → 모델 연결)에서 **Qwen, DeepSeek, OpenAI, SiliconFlow, 로컬 호환 서비스, 사용자 지정**을 선택합니다. 프리셋은 주소와 모델 제안을 채웁니다. Qwen은 `qwen-flash` 또는 `qwen-plus`를 제안하며 지역과 작업 공간을 직접 지정해야 합니다. SiliconFlow는 모델을 자동 선택하지 않습니다. 제공업체/지역별 설정과 키를 기억하지만 한 번에 하나만 활성화합니다. 선택과 입력은 초안만 변경합니다. 작업이 없을 때 **변경 사항 저장**으로 함께 저장하고 전환하며, 실패하면 이전 설정을 유지합니다. 재시작이나 자동 요청은 없습니다.

**다듬기 테스트**는 저장하지 않은 API 초안을 가상의 중·영문 샘플, 실제 다듬기 규칙, 12초 제한으로 확인합니다. 주소·모델·키를 바꾸면 이전 결과는 무효입니다. **모델 가져오기**는 직접 실행하며 최대 10초, 500개 모델, 2 MiB로 제한합니다. 실패하거나 지원하지 않아도 제안 선택과 직접 입력은 유지됩니다. 목록에 있거나 한 샘플을 통과해도 전반적인 품질을 보장하지 않습니다.

키는 설정과 엔드포인트별로 분리됩니다. 빈칸은 해당 설정의 키를 유지하고, **키 제거**는 저장 전에 취소할 수 있습니다. 새 키는 시스템 암호화를 선택하지 않으면 현재 세션에서만 사용합니다. 주소 변경에는 키 교체 또는 제거를 명시해야 하며 암호화·쓰기 실패 시 저장 전체를 취소합니다. 키를 사용할 수 없으면 이번 구간은 로컬 받아쓰기로 계속하며 저장된 기본 설정이나 제공업체를 자동 변경하지 않습니다.

텍스트 **Chat Completions**만 지원하고 다듬기 요청은 스트리밍으로 보내며(JSON을 한 번에 반환하는 서비스도 처리) API 환경 변수나 `.env` 설정은 없습니다. 프리셋 문서는 2026-10-28에 확인했으며 실제 계정 검증은 아닙니다. 로컬 텍스트 서버는 포함하지 않습니다. 필드, 키 발급 링크, 지역·목록 제한과 문제 해결은 [API 설정](../API_CONFIGURATION.md)을 보세요. **샘플 테스트와 직접 실행한 재시도는 과금될 수 있으며 취소해도 원격 과금 중단을 보장하지 않습니다.**

## 개인정보와 로컬 저장

- 로컬 인식과 사전 교정에는 API가 필요하지 않습니다. 현재 제품은 새로운 녹음 파일을 저장하지 않습니다. 복구용 오디오는 임시 메모리에 있으며, 만료·지우기·앱 종료 시 버립니다. 비정상 종료 후 복구는 보장하지 않습니다.
- **가장 최근 결과는 원문과 편집본을 포함하여 로컬에 평문으로 저장됩니다.** 여러 항목의 기록을 꺼도 이 저장은 이루어집니다. 전사문 자동 만료나 보관 설정은 없습니다. 개발 데이터는 Git에서 제외되는 `work/dev/profile/`에 있으므로 절대 커밋하지 마세요.
- 다듬기를 켜면 교정된 전사문과 크기가 제한된 올바른 사전 용어 목록을 설정한 서비스로 보냅니다. 원본 오디오와 오인식 표기 별칭은 포함하지 않습니다. 서비스 제공업체의 보관 및 과금 정책이 적용됩니다.
- 새 키는 암호화 저장을 선택하지 않으면 현재 세션에서만 사용합니다. 저장한 키는 Electron의 운영체제 기반 저장소를 사용하며, 사용할 수 없을 때 평문으로 대신 저장하지 않습니다. 같은 운영체제 사용자 권한으로 실행되는 악성 프로그램까지 막아 주지는 않습니다.
- 사용량 기록에는 요청, 모델, 시간, 토큰 메타데이터만 포함되며 본문이나 키는 포함되지 않습니다. 사용량이나 가격 정보가 없으면 비용은 0이 아니라 알 수 없음입니다.

개인적인 자료를 사용하기 전에 [개인정보 안내](../PRIVACY.md)를 읽어 주세요. 로컬 인식이라고 해서 선택적 다듬기가 아무것도 업로드하지 않거나, 텍스트가 디스크에 전혀 저장되지 않는다는 뜻은 아닙니다.

## 언어, 제약 사항, 검증

UI는 **중국어 간체**와 **영어**를 지원하며, 이 예시는 영어 화면입니다. 문서가 여섯 언어로 제공된다고 해서 UI나 음성 인식도 여섯 언어를 모두 지원하는 것은 아닙니다. SenseVoice 원 프로젝트가 명시한 언어는 표준 중국어, 광둥어, 영어, 일본어, 한국어입니다. 과거의 고정 파일 평가는 표준 중국어와 영어를 대상으로 했습니다. 프랑스어 및 말레이어 인식을 지원한다고 주장하지 않습니다.

UI 언어는 Windows 표시 언어를 따릅니다(중국어 시스템은 중국어, 그 외는 영어). 설정 → 인터페이스 언어에서 바꿀 수 있으며 재시작 후 적용됩니다. 개발 인스턴스에서는 `npm run dev -- --ui-language=en` 또는 `--ui-language=zh-CN`으로 고정할 수 있습니다. 표시 언어만 바꾸며 받아쓰기 결과나 사전 내용은 변경하지 않습니다.

이 저장소에는 앱 본체의 소스와 사용 문서가 포함됩니다. 내부 테스트 데이터와 성능 보고서는 포함하지 않습니다. 전역 단축키, 시스템 클립보드, 마이크 변경, 포커스, 다중 화면, Windows DPI, 실제 서비스 품질과 새 환경 설치는 별도 검수가 필요합니다.

이전 벤치마크는 해당 컴퓨터와 평가 자료에만 적용되며 보편적인 속도나 정확도를 뜻하지 않습니다. 패키징 검사는 명시적으로 **`distributionReady:false`**를 보고합니다.

## 문제 해결

| 문제 | 확인할 사항 |
| --- | --- |
| 런타임 또는 모델이 없음 | `npm run doctor`를 실행하고 외부 리소스의 전체 구성, 버전, 라이선스 고지를 확인하세요. |
| 음량 표시가 움직이지 않거나 음성을 감지하지 못함 | 실제로 작동하는 마이크를 이름으로 선택하고 저장하세요. Windows 권한과 음소거를 확인한 뒤 직접 녹음하세요. 시스템 기본 장치가 다른 입력일 수 있습니다. |
| API가 설정되어 있지 않음 | 다듬기를 끄세요. 로컬 인식과 사전 규칙은 계속 사용할 수 있습니다. |
| 401/403 또는 404 | 키, 지역, 권한, 모델 ID, Chat Completions 주소를 확인하세요. 이슈에 키를 붙여넣지 마세요. |
| 요청 제한 또는 시간 초과 | 보존된 텍스트를 사용하세요. 재시도는 직접 결정해야 하며 이전 요청에도 요금이 발생할 수 있습니다. |
| 저장 실패 | 초안을 유지하고 중요한 텍스트를 복사한 뒤, 디스크 공간과 쓰기 권한을 확인하고 재시도하세요. |
| TLS 또는 네트워크 오류 | 공식 호스트, 운영체제 시계, 인증서 신뢰 체인, 방화벽을 확인하세요. 인증서 검증을 끄지 마세요. |
