# Dictpin

**小さなデスクトップ音声入力ツール。話して、自分の言葉を確かめて、次の作業へ。**

**AI で生成したコンセプト画像です。実際のソフトウェア画面や、実装済み機能を示すものではありません。**

Dictpin は、Electron、ローカルで動く SenseVoice 音声認識、ユーザーが明示的に登録する辞書ルール、互換サービスによる任意のテキスト整形を組み合わせた、Windows 向け音声入力アプリの開発候補版です。短いメッセージ、メモ、人名、専門用語などを、開始、発話、確認、コピーの流れで扱います。

> **ソースコードとして公開する開発候補版です。** リポジトリ：[chenjinxian1/Dictpin](https://github.com/chenjinxian1/Dictpin)。独自のコードとプロジェクト素材は chenjinxian1 の MIT ライセンスで公開し、第三者のコンポーネントにはそれぞれの条件が適用されます。検証済みのインストーラーやリリースのダウンロードはありません。Dictpin は初期の名称調査を経た名称であり、商標の使用可能性を保証するものではありません。パッケージ ID とデータ保存先は従来の名称を維持します。本プロジェクトは Typeless とは独立しており、公式な関係はありません。

## 現在実装されている機能

- **ローカル音声認識：** CPU 上の SenseVoice と Silero の音声区間検出を使用します。クラウド認識への自動切り替えはありません。
- **明示的な辞書補正：** 正しい語句と、必要に応じてよくある誤表記を登録します。ローカルで一度だけ走査し、一致する最長のルールを優先して置き換えます。同音語の推測や自動学習は行いません。補正内容を確認し、取り消すことができます。
- **整形の完了前から使える文章：** すぐに編集やコピーができます。どちらの操作でも進行中の整形を終了し、遅れて届いた応答がその版を上書きすることを防ぎます。認識原文は別途残ります。
- **ユーザー操作による復元：** 完全な音声区間が取得できている場合、キャンセル後は 30 秒間、認識失敗後は最大 5 分間、メモリ内に限って復元できます。再試行にはクリックが必要です。復元時はリモート整形を無効にします。
- **小さな作業空間：** 結果、辞書、設定の 3 ページと、フローティング録音バーで構成されています。ライト／ダークテーマ、高コントラスト、動きの軽減、キーボードのフォーカス表示を実装しています。
- **任意の軽い整形：** テキスト用 Chat Completions サービスを通じて、句読点、段落、言いよどみを整えます。失敗した場合や 12 秒の期限に達した場合でも、ローカルで補正済みの文章を使えます。

実際の利点は、文章を自分で管理できること、辞書ルールがオフラインで働くこと、失敗してもすぐに録り直さず復元できることです。あらゆる条件での認識精度、遅延、メモリ使用量、他製品に対する性能優位はうたっていません。翻訳、質問応答、文章の拡張、自動貼り付け、大規模な履歴ダッシュボードは対象外です。

## 基本の流れ

```text
明示的に開始 → 選択したマイク → ローカル音声認識
             → 明示的な辞書ルール → 任意のテキスト整形
             → 確認／編集 → 明示的にコピー
```

一度に処理するのは 1 区間です。録音区間の上限は 60 秒で、録音は約 58 秒で停止します。整形中に **复制文字**（文章をコピー）を押すと、表示中の版をコピーして整形を終了します。メインウィンドウでは `Ctrl+Enter` で結果全体をコピーでき、`Ctrl+C` は通常どおり選択部分をコピーします。任意の「最新の結果をコピー」グローバルショートカットは、初期状態では未割り当てです。

## クイックスタート：開発環境

**現在の対象は Windows x64 です。** Node.js **24 以降**をインストールしてください。Electron **44.8.0** の完全な外部配布一式、sherpa-onnx **1.13.8** の共有ランタイム、SenseVoice int8 モデルと tokens、Silero VAD モデル、別途用意する Local03 ネイティブワーカーが必要です。これらのリソースは同梱していません。[インストール手順](../INSTALL.md)に記載した正確な配置と公式の入手先を確認してください。

リソースを準備した後、リポジトリのルートで実行します。

```powershell
.\native\build-local03.cmd
npm run doctor
npm run check
node scripts/package-inputs.cjs
npm run dev
```

ルートのスクリプトは Node 組み込みモジュールを使うため、ルートで依存パッケージをインストールする手順はありません。`doctor` は既存の配置を確認するもので、新規環境への導入や認識品質を保証しません。`dev` は開発用プロファイルを開きますが、録音は開始しません。過去の bootstrap やセッション復帰用スクリプトから起動しないでください。

**API なしでローカル利用する場合**は、**轻整理**（軽い整形）をオフにします。**设置**（設定）を開き、Windows の録音アプリで実際に使っているマイクを選び、**保存更改**（変更を保存）を押してから、明示的に音声入力を開始します。保存していないマイク選択は有効になりません。停止後に文章を確認してコピーしてください。ショートカットは必要な場合だけ設定します。

`npm run check` はアプリの構文、ローカル依存関係、配布対象ファイル、文書を確認します。テスト、性能評価、旧画面、内部の公開準備ツールはこのリポジトリに含めません。[検証とビルドの現状](../INSTALL.md#validation-and-build-status)をご覧ください。検証済みのインストーラー作成コマンドはありません。

## 任意の API 設定

**设置 → 模型连接**（設定 → モデル接続）で、API のアドレス、正確なテキストモデル ID、キーを入力します。キーをシステムの安全なストレージに保存するか選択できます。処理中でないときに保存し、その後で軽い整形を有効にします。再起動は不要です。環境変数や `.env` による API 設定には対応していません。

ここで対応しているのは**テキスト用 Chat Completions** のみです。ASR、TTS、Responses、DashScope 独自の音声エンドポイントには対応していません。Qwen の利用は任意です。同じリージョンとワークスペースに対応するアドレス、キー、利用可能なテキストモデル（例：`qwen-plus`）を指定してください。互換アドレスは提供元の管理画面からコピーします。1 つの例をすべての環境で使えるわけではありません。互換性のあるローカルテキストサーバーも設定できますが、アプリには同梱していません。

正確な項目、公式のキー取得先、設定例、問題の切り分けは [API 設定](../API_CONFIGURATION.md)をご覧ください。**接続テストや、明示的に行う整形の再試行には料金が発生する場合があります。**

## プライバシーとローカル保存

- ローカル音声認識と辞書補正に API は不要です。現在の製品は新しい録音ファイルを保存しません。音声の復元は一時的なメモリだけを使い、期限切れ、消去、アプリ終了で破棄します。クラッシュ後の復元は保証できません。
- **最新の結果は原文と編集後の文章を含め、ローカルに平文で保存されます。** 複数件の履歴をオフにしても保存されます。文字起こしの自動失効や保存を無効にする設定はありません。開発データは Git の対象外である `work/dev/profile/` に保存されます。コミットに含めないでください。
- 整形を有効にすると、補正済みの文字起こしと、辞書に登録された正しい語句のうち件数を制限したリストを、設定したサービスに送信します。元の音声や誤表記の別名は含みません。提供元の保存方針と課金条件が適用されます。
- 新しいキーは、暗号化して保存する設定を選ばない限り、そのセッションだけで使われます。保存したキーには Electron が提供する OS ベースの安全なストレージを使います。利用できない場合に平文保存へ切り替えることはありません。ただし、自分の OS ユーザー権限で動くマルウェアから守るものではありません。
- 利用記録にはリクエスト、モデル、所要時間、トークンなどのメタデータが含まれますが、本文やキーは含みません。利用量や料金情報がない場合は、費用が不明という意味であり、無料を意味しません。

私的な内容を扱う前に[プライバシー](../PRIVACY.md)を読んでください。ローカル認識だからといって、任意の整形で何も送信されない、あるいは文章がディスクに一切書き込まれないという意味ではありません。

## 対応言語、制限、検証範囲

UI の既定言語は**簡体字中国語**で、任意の**英語表示モード**もあり、この例では英語表示を使用しています。6 言語の文書があっても、UI や音声認識がその 6 言語すべてに対応するわけではありません。SenseVoice の提供元は、中国語普通話、広東語、英語、日本語、韓国語を挙げています。過去の固定音声ファイルによる評価は中国語普通話と英語が対象です。フランス語とマレー語の認識には対応をうたっていません。

英語表示で起動するには `npm run dev -- --ui-language=en` を実行します。指定しない場合は既定の中国語表示です。表示だけを切り替え、文字起こしや辞書の内容は変更しません。

このリポジトリにはアプリ本体のソースと利用文書を収録しています。内部テスト用データや性能報告は含めません。グローバルショートカット、システムのクリップボード、マイクの変更、フォーカス、複数画面、Windows DPI、実際のサービス品質、新規環境への導入は別途確認が必要です。

過去のベンチマークは、そのマシンと音声集合に限る結果であり、普遍的な速度や精度を示すものではありません。パッケージ検査は明示的に **`distributionReady:false`** を返します。

## よくある問題

| 問題 | 確認すること |
| --- | --- |
| ランタイムやモデルが見つからない | `npm run doctor` を実行し、外部リソースの配置全体、バージョン、ライセンス表記を確認してください。 |
| 音量表示が動かない、音声を検出しない | 実際に動作するマイクを名前で選んで保存し、Windows の権限やミュートを確認したうえで、明示的に録音してください。システム既定の入力が別の機器である場合があります。 |
| API を設定していない | 整形をオフにしてください。ローカル音声認識と辞書ルールは使えます。 |
| 401/403 または 404 | キー、リージョン、権限、モデル ID、Chat Completions のアドレスを確認してください。Issue にキーを貼り付けないでください。 |
| レート制限やタイムアウト | 保持された文章を使ってください。再試行は自分で判断して実行してください。前のリクエストにも料金が発生する場合があります。 |
| 変更を保存できない | 下書きを保持し、大切な文章をコピーしてください。空き容量と書き込み権限を確認してから再試行します。 |
| TLS やネットワークのエラー | 公式の接続先、OS の時計、証明書の信頼チェーン、ファイアウォールを確認してください。証明書検証を無効にしないでください。 |
